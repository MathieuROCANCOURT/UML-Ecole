| Elément | Description |
| --- | --- |
| Nom du cas d’utilisation | Regarder ses cours |
| But / Objectif | Avoir accès à ses cours en tant qu'élève |
| Acteur principal | Élève |
| Acteur secondaire | Directeur |
| Préconditions | <ul><li>Avoir un compte élève.</li><li>Être connecté à l'application.</li></ul> |
| Scénario principal | <ol><li>L'élève clique sur « Accéder à mes cours ».</li><li>Le système vérifie que l'utilisateur possède un compte élève.</li><li>Le système affiche les cours associés à l'élève.</li><li>L'élève consulte le cours de son choix.</li></ol> |
| Scénarios alternatifs | <ul><li>L'utilisateur ne possède pas de compte élève : redirection vers la page de connexion.</li><li>L'utilisateur n'est pas connecté : redirection vers la page de connexion.</li></ul> |
| Postconditions | <ul><li>L'élève a accès à ses cours.</li><li>Les cours de l'élève sont affichés.</li></ul> |
