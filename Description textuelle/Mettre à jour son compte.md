| Elément | Description |
| --- | --- |
| Nom du cas d’utilisation | Mettre à jour son compte |
| But / Objectif | Mettre à jour son adresse |
| Acteur principal | Utlisateurs |
| Acteur secondaire | Aucun |
| Préconditions | Être connecté à son compte. |
| Scénario principal | <ol><li>L'utilisateur accède à son profil.</li><li>L'utilisateur clique sur « Mettre à jour ».</li><li>L'utilisateur saisit sa nouvelle adresse (rue, ville, code postal).</li><li>L'utilisateur valide les modifications.</li><li>Le système enregistre les nouvelles informations.</li></ol> |
| Scénarios alternatifs | <ul><li>L'utilisateur n'est pas connecté : redirection vers la page de connexion.</li><li>Les informations saisies sont invalides : affichage d'un message d'erreur.</li></ul> |
| Postconditions | Les informations du compte sont mises à jour. |
